*Asegúrese de que el servidor backend esté corriendo en el puerto 8001 para que las peticiones se completen correctamente.

*Requisitos
Node.js: v18.0.0 o superior.
NPM: v9.0.0 o superior.

*Para ejecutar el proyecto, abra dos terminales: una en la carpeta del backend y otra en la carpeta frontend.

*Ejecutar:
git clone <vr-in-situ-prueba-frontend>
cd frontend-vris
npm install
npm run dev

*URL Base: http://localhost:8001/api
